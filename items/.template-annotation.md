## Cost / sale tracking

`ledger` blocks here are the only place cost/margin data lives — never in the
published note's body. Compiled into the real journal by
`pfinds:.tools/gen-items-journal.py`. See
`claude:nbweb-hledger_plugin_design.md` "Item annotation workflow" for the
full explanation, including which `sold` shape to use.

```ledger
; --- acquired ---
YYYY-MM-DD Source — description
    Assets:Inventory              0.00 CAD
    Assets:Bank:Business:Chequing
```
